# Solar Docs Control

> 🔒 **Showcase** — the source code is private. Walkthrough available on request via [LinkedIn](https://www.linkedin.com/in/acsamiloglu/).

A queryable document-control system for solar / BESS projects. It indexes handover packs, checklists, test reports and contracts, and answers questions with exact citations.

## Features
- Every answer cites **file + page** (and contract clause where relevant)
- Documents organised per site — answers never mix sites
- Says "not found" instead of guessing
- Used from Claude through an MCP server

## Tech stack
Python · SQLite · MCP
